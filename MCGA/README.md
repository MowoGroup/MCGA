# MCGA — Make Commits Great Again

Claude Code skill, который превращает обычные сообщения git-коммитов в драматичные твиты в стиле Дональда Трампа. На русском. С КАПСОМ. С восклицаниями!

> Лучший скилл для коммитов в истории. Поверьте мне.

---

## Пример

**Было:**

```
fix: исправил утечку токенов в auth-middleware
```

**Стало:**

```
fix: КАТАСТРОФА в auth — ИСПРАВЛЕНО!

JWT-токены УТЕКАЛИ годами. Прошлая команда ЗНАЛА. Молчала.
Мы пришли. Посмотрели. ИСПРАВИЛИ. Лучший фикс в истории.

ПЕЧАЛЬНО, что это так долго!
```

## Установка

Skills в Claude Code лежат в одной из двух директорий:

| Уровень | Путь | Когда применять |
|---|---|---|
| Пользовательский | `~/.claude/skills/MCGA/` | Доступен во всех проектах. |
| Проектный | `<repo>/.claude/skills/MCGA/` | Только в этом репозитории. |

### Вариант 1 — через `git clone` (рекомендую)

Склонируй репо один раз, потом скопируй подпапку `MCGA/` в свою папку скиллов:

```bash
# клонируешь куда угодно
git clone https://github.com/MowoGroup/MCGA.git /tmp/mcga-skills

# глобально (для всех проектов)
cp -r /tmp/mcga-skills/MCGA ~/.claude/skills/MCGA

# или локально, в конкретный проект
cp -r /tmp/mcga-skills/MCGA <your-repo>/.claude/skills/MCGA
```

### Вариант 2 — скачать руками

Скачай `SKILL.md` из этой папки и положи в `~/.claude/skills/MCGA/SKILL.md`. Это единственный обязательный файл — `README.md` нужен только для GitHub.

### Проверка

Запусти Claude Code и в любом проекте напиши:

```
сделай мне MCGA-коммит
```

Если скилл подхватился — Claude начнёт работать по сценарию ниже.

## Как использовать

Скилл активируется, когда ты пишешь Claude что-то из этого:

- `MCGA`
- `Make Commits Great Again`
- `коммит в стиле Трампа`
- `трампанутый коммит`
- `сделай коммит великим`
- `/mcga` (если оформлено как команда)

Сценарий:

1. Ты даёшь обычное сообщение коммита — **или** просто говоришь «MCGA», и Claude сам посмотрит `git diff --cached`.
2. Claude генерирует драматичную версию по правилам стиля.
3. Показывает результат. **Не коммитит сам** — ждёт твоего «да».
4. По подтверждению вызывает `git commit -m "..."`.

## Правила стиля (коротко)

Полный набор — в [SKILL.md](./SKILL.md). Главное:

1. **КАПС только на ключевых словах** (КАТАСТРОФА, ИСПРАВЛЕНО, ВЕЛИКО), не вся строка.
2. **Рубленые предложения.** Подлежащее. Сказуемое. Точка.
3. **2–3 восклицания** на сообщение.
4. **Самовосхваление** («Лучший фикс в истории», «Никто не делает лучше»).
5. **Обвинение прошлого** («Прошлая команда ЗНАЛА. Молчала.»).
6. **Финальная эмоция** отдельной строкой: `ПЕЧАЛЬНО!`, `ПОЗОР!`, `ВЕЛИКО!`, `ОГРОМНЫЙ УСПЕХ!`.
7. **Без эмодзи и markdown.**
8. **Заголовок ≤ 72 символа.** Тело — 3–6 строк.
9. **Смысл сохраняется** — из коммита должно быть понятно, что изменилось.
10. **Префикс `fix:` / `feat:` / `refactor:`** остаётся в нижнем регистре.

### Финал по типу коммита

| Тип | Финальная строка |
|---|---|
| `fix:`      | `ПЕЧАЛЬНО, что это так долго!` |
| `feat:`     | `ОГРОМНЫЙ УСПЕХ!` |
| `refactor:` | `Теперь — КРАСИВО!` |
| `perf:`     | `БЫСТРО. Очень быстро!` |
| `docs:`     | `Наконец-то ЯСНО!` |
| `chore:`    | `Порядок. НАСТОЯЩИЙ порядок!` |
| `test:`     | `ТЕПЕРЬ мы знаем. Точно знаем!` |

## FAQ

**Подойдёт для рабочих репозиториев?** Решай сам. В сериозных продуктовых репах коллеги вряд ли оценят `КАТАСТРОФА ИСПРАВЛЕНО` в `git log`. Лучше для пет-проектов, hackathon-ов и pet-репозиториев.

**А по-английски?** Есть отдельный скилл [MCGA-EN](../MCGA-EN/) — тот же стиль, но на английском (DISASTER, FIXED, HUGE, SAD!).

**Можно ли подправить тон?** Да. Открой `SKILL.md`, поправь правила, примеры или таблицу финалов под себя.

**Будет ли коммитить автоматически?** Нет. Скилл показывает результат и ждёт твоего «да». `git commit` запускается только с подтверждением.
